**Antes de la práctica:** Antes de realizar esta práctica, mi manejo de Docker se centraba principalmente en el despliegue de contenedores a partir de imágenes existentes descargadas desde Docker Hub mediante comandos directos en consola.

**Despúes de la práctica:** Comprendí cómo automatizar y personalizar la construcción de imágenes propias desde cero utilizando un archivo Dockerfile.

**Beneficio para mi formación profesional:** Entendí que cada instrucción FROM, RUN, COPY, EXPOSE, CMD genera una capa inmutable y que Docker reutiliza las capas que no han sufrido cambios, además aprendí por qué el proceso principal dentro de un contenedor como Apache con apachectl -D FOREGROUND debe mantenerse en primer plano para evitar que el contenedor se detenga inmediatamente.
